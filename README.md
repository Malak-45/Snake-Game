🐍 A classic Snake Game built with C++! 🎮

✨ Features:
🍎 Food collection and snake growth
💥 Wall and self-collision detection
⭐ Score tracking and high score saving
🚀 Increasing speed and difficulty levels
⏸️ Pause and resume functionality
🎯 Menu and difficulty settings

💻 Built using C++, basic OOP, vectors, and functions — a fun project to practice programming fundamentals!
